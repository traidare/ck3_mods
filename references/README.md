# CK3 reference material

This directory contains the generic CK3 and AGOT guides tracked by this
repository. The ignored `generated/` cache is populated from the configured
`CK3_GAME_DIR` and `CK3_PARADOX_DIR`; it is never a source of host-specific
paths in version control.

Conceptual CK3 wiki material is indexed separately as the
`ck3_modding_wiki_pages` codebase-memory project. The repository intentionally
does not contain an absolute symlink to another checkout.
