# AGOT - Adventurer Tweaks

Small rule changes for landless adventurers in **A Game of Thrones**, built
against the current release so nothing in AGOT is rolled back.

## Requirements and load order

Requires **A Game of Thrones**. Load after it.

## What it changes

- **Royal bastards can act while landless.** Revealing your own true parentage
  and pressing a royal bastard's claim no longer require you to hold land. A
  landless adventurer can use both. Ordinary unlanded courtiers still cannot.
- **Evicting an adventurer is a county-level power.** Only the holder of the
  county the camp sits in can evict it, and only if they are a count. Lieges
  further up the chain can no longer evict a camp in a vassal's county, and a
  county held directly by a duke or higher cannot evict at all.

Everything else about these decisions and the eviction interaction — costs, AI
behaviour, war consequences, story blockers — is AGOT's own and unchanged.

## Not included

Dragon egg stealing is deliberately left alone. **AGOT More Dragon Eggs**
already covers it, and this mod stays out of its way.
