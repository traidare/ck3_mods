# AGOT - More Personality Depth + Dragon Wives Compatch

Compatibility patch for the shared character window.

## Requirements and load order

1. A Game of Thrones
2. AGOT Dragon Wives
3. AGOT - More Personality Depth
4. AGOT MPD - CK3 1.19 Runtime Rebase
5. This compatch

## What it does

Merges Dragon Wives' special family rows into AGOT's current character window
and preserves More Personality Depth's personality display for player
characters, so enabling both mods no longer costs you one of the two.

This mod contains only that cross-mod GUI merge. More Personality Depth's
runtime repairs live in the preceding **AGOT MPD 0.4.0 - CK3 1.19 Runtime
Rebase**, which is useful on its own without Dragon Wives.
