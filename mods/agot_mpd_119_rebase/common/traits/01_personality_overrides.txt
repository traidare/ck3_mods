# (Mild / Normal / Intense via XP track at thresholds 1 / 50 / 100).
#
# Opinion overhaul (core MPD feature): opinion modifiers scale per level.
#   - L1 (Mild)     = round(L2 × 0.5)
#   - L2 (Normal)   = baseline magnitude (Mayham-aligned)
#   - L3 (Intense)  = round(L2 × 1.5)
# This makes a Furious character far more disliked than a Quick-Tempered one.
#
# Non-opinion modifiers (skills, dread, mults, AI values, combat rolls, scheme
# modifiers): same value across all 3 levels. Only opinions scale.
#
# Some culture_modifier blocks reference parameters defined by the aGoT: Mayham
# mod (e.g. wrathful_trait_looked_down_upon). Without Mayham loaded those
# parameters do not exist and the modifier silently never fires — no errors.
#
# Dynamic name + desc: triggered_desc lookups switch the displayed string per
# XP level (e.g. wrathful → Quick-Tempered / Wrathful / Furious).
