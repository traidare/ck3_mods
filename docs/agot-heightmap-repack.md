# AGOT heightmap repack workflow

This workflow activates the small NOW elevation delta preserved by the local
NOW + LoV + Essos Expanded map compatch. CK3's map editor must convert the
merged `heightmap.png` into a matching runtime set.

The runtime heightmap is a coherent quartet:

- `heightmap.png`, the editable source;
- `heightmap.heightmap`, the topology metadata;
- `packed_heightmap.png`, the packed runtime elevation;
- `indirection_heightmap.png`, the lookup table into the packed data.

Never install the merged source without the three matching files generated by
the same editor repack. Keep Essos Expanded's `nodes.dat`; this workflow does
not replace it.

The helper treats Workshop content and the CK3 installation as read-only. It
loads the repository `.env`, with already-exported variables taking precedence.
Close CK3 and the Paradox Launcher before importing a playset or promoting
output.

## Command reference

```text
scripts/agot-heightmap-repack.bash prepare [options]
scripts/agot-heightmap-repack.bash verify [options]
scripts/agot-heightmap-repack.bash promote [options] --yes
scripts/agot-heightmap-repack.bash import-playset [options] [--dry-run]
scripts/agot-heightmap-repack.bash unregister [options]
```

- `prepare` creates and registers the writable staging mod, seeds its packed
  files from Essos Expanded, records pre-repack hashes, and generates the
  ignored minimal playset.
- `verify` checks the source, formats, dimensions, topology settings, and
  decoded packed-pixel changes without modifying the real compatch.
- `promote --yes` verifies, backs up any existing local quartet, and installs
  the staged quartet into the real compatch.
- `import-playset` imports the minimal editor playset;
  `import-playset --dry-run` only resolves and reports it.
- `unregister` moves the temporary launcher descriptor into the staging
  directory without deleting the stage.

Available options:

- `--stage DIR` selects a custom stage. Registered preparation requires the
  default stage; combine this with `--no-register` for another location.
- `--workshop-dir DIR` overrides `CK3_WORKSHOP_DIR`.
- `--paradox-dir DIR` overrides `CK3_PARADOX_DIR`.
- `--no-register` prepares without writing a launcher descriptor.
- `--dry-run` applies to `import-playset`.
- `--yes` is mandatory for `promote`.

The default registered stage is:

```text
$CK3_PARADOX_DIR/mod/agot_heightmap_repack_staging/
```

## Prepare the editor mod

Close CK3 and run:

```sh
scripts/agot-heightmap-repack.bash prepare
```

Its launcher descriptor uses the relative path
`mod/agot_heightmap_repack_staging`. Keeping the stage inside the CK3 user-data
directory ensures that the launcher and game see the same filesystem path.

Start the Paradox Launcher once so it discovers `AGOT Heightmap Repack Staging`,
then close the launcher completely. Import the minimal playset:

```sh
scripts/agot-heightmap-repack.bash import-playset --dry-run
scripts/agot-heightmap-repack.bash import-playset
```

## Repack in CK3

Add these temporary Steam launch options:

```text
-mapeditor -debug_mode
```

Select `AGOT - Heightmap Editor (Minimal)` and launch CK3. AGOT may spend a long
time initializing its character database before showing the editor. Previous
testing was still processing roughly 49,700 living characters after 15 minutes
and reached approximately 45 GiB resident memory, so ensure that the machine has
ample RAM and swap.

In the editor:

1. Open the heightmap or terrain tool.
2. Confirm that the map is the 9216 by 6144 Essos Expanded map.
3. Select **Repack**.
4. Keep the preselected **33x33** tile size.
5. Leave **Wrap X** disabled.
6. Start the repack and wait for it to finish.
7. Save the editor output.
8. Keep the editor open until the output location is confirmed.

These settings preserve Essos Expanded's existing topology configuration:
`tile_size=33` and `should_wrap_x=no`. The 65x65 and 129x129 choices would
change the packed topology, while horizontal wrapping is inappropriate for this
map.

The expected destination is:

```text
$CK3_PARADOX_DIR/mod/agot_heightmap_repack_staging/map_data/
```

The script never deletes base-game packed files. If this CK3 editor version
instead writes into the base game's `game/map_data`, manually copy the three new
packed files into the staging directory and restore or verify the game
installation before continuing.

## Verify and promote

After closing CK3:

```sh
scripts/agot-heightmap-repack.bash verify
```

Verification requires:

- a 9216 by 6144, 16-bit grayscale merged source whose decoded pixels are
  unchanged (the editor may harmlessly re-encode the PNG during Save);
- matching paths and dimensions in `heightmap.heightmap`;
- a 33 by 33 tile size with horizontal wrapping disabled;
- a 288 by 192 indirection image;
- 16-bit grayscale packed data;
- a packed-data hash and decoded-pixel signature different from the Essos
  Expanded seed.

If verification passes, promote the four-file set:

```sh
scripts/agot-heightmap-repack.bash promote --yes
just install
just check-tiger agot_now_lov_ee_map_compatch
scripts/ck3-playsets.py export > /tmp/agot-playset.json
ck3_mod_conflict_checker \
  -playset /tmp/agot-playset.json \
  -involving mod/agot_now_lov_ee_map_compatch.mod
```

Promotion copies `heightmap.png`, `heightmap.heightmap`, `packed_heightmap.png`,
and `indirection_heightmap.png` together. It does not copy `nodes.dat`; Essos
Expanded remains the source for that file.

Test both the map editor and a new normal game before trusting the result. Check
coastlines, borders, rivers, title highlighting, and the north of the map. A
black or missing northern map, displaced borders, or an editor crash on the
second load means the generated set should not be used.

## Unregister the temporary mod

Once testing is complete:

```sh
scripts/agot-heightmap-repack.bash unregister
```

This moves the launcher descriptor into the staging directory instead of
deleting it. The staging directory and generated artifacts remain available for
inspection or recovery.
